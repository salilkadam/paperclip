Plan next week's social posts for each channel the company has connected in
TryPost, using that channel's content planner skill (`linkedin-content-planner`,
`x-content-planner`, `ig-content-planner`, `yt-content-planner`,
`threads-content-planner`, `tt-content-planner`, `fb-content-planner`). Review last
week's published posts with `get-post-metrics-tool` first. Create one task per
planned post, draft the first ones as TryPost drafts, and request go-live only as
the `social-core` skill describes.
