## 1. The manifest

The manifest is the project's state file. Change one scene's assets, re-run, get a new
cut — that is what makes feedback cheap.

```json
{
  "output": "final.mp4",
  "music": "music.mp3",
  "music_volume": 0.52,
  "tail": 0.5,
  "font": "/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf",
  "scenes": [
    {"name":"s1","type":"still","still":"img1.png","vo":"vo/scene1.wav",
     "caption":"Hook line","sub":"","zoom":"in"},
    {"name":"s2","type":"broll","clip":"clips/s2.mp4","vo":"vo/scene2.wav",
     "caption":"Second beat","sub":""},
    {"name":"a3","type":"avatar","clip":"clips/a3_i30.mp4","bg":"img3.png",
     "caption":"Brand","sub":"Location"}
  ]
}
```

`music_volume` 0.45-0.62 is the usable band. `tail` is dead air after the VO before
cutting — 0.4-0.5s stops it feeling clipped.

## 2. Scene types

**`still`** — Ken-Burns over a static image, VO audio. Duration = VO + tail.
```
scale=2560:1440,zoompan=z='min(1.0+0.0010*on,1.14)':d=<frames>:
  x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':s=1280x720:fps=30
```
`zoom: "out"` reverses it (`max(1.14-0.0010*on,1.0)`). Alternate direction between
adjacent stills so a montage doesn't pulse.

**`broll`** — motion clip + VO. Duration = VO + tail.
Default fits a square avatalk clip to 16:9 by scale-and-crop, which is correct for raw
square output. For clips already un-padded to 16:9 (see `geometry.md`) that would crop
again — use the no-crop path (`scale=1280:720` directly).

If the clip is shorter than the scene, slow it *forward*; never boomerang (the reverse
is visible). Prefer pre-stretching with motion interpolation.

**`avatar`** — square presenter over a blurred background plate, using the clip's own
audio.
```
[0:v]scale=1280:720:force_original_aspect_ratio=increase,crop=1280:720,
     boxblur=26:2,eq=brightness=-0.30:saturation=0.85[bg];
[1:v]scale=720:720,fps=30[fg];
[bg][fg]overlay=(W-w)/2:(H-h)/2:shortest=1[ov]
```
The background still **must** be input with `-loop 1`. Without it, `shortest=1` sees a
one-frame input and the whole scene collapses to a single frame.

## 3. Normalise before concat

avatalk output is variable-frame-rate with container duration ≠ frame count. Concat with
`-c copy` across VFR clips silently drops frames and truncates the ending.

Force CFR 30 at each clip's own audio length first:
```
-vf "tpad=stop_mode=clone:stop_duration=3,fps=30,trim=0:<A>,setpts=PTS-STARTPTS"
-af "apad,atrim=0:<A>,asetpts=PTS-STARTPTS"
-r 30 -vsync cfr -t <A>
```
where `<A>` is the clip's audio duration. Cloning the last frame covers any video that
runs short. Do this for **every** clip, then concat.

## 4. Captions

Burned in by ffmpeg, never generated by the video model — that is why on-screen text is
crisp here and garbled in text-to-video tools. Put anything that must be legible (URLs,
dates, prices) in a caption rather than the narration.

```
drawtext=fontfile=<FONT>:text='<caption>':fontcolor=white:fontsize=52:
  box=1:boxcolor=black@0.45:boxborderw=22:x=(w-text_w)/2:y=h-165:
  alpha='if(lt(t,0.3),0,if(lt(t,0.7),(t-0.3)/0.4,1))'
```
Optional sub-caption 30px, accent colour, at `y=h-98`, fading in slightly later.

Escape `:` and `\` in text; replace `'` with a typographic `’`. At fontsize 52 roughly
40 characters fit across 1280 — longer captions collide with the frame edge, so split
into caption + sub.

## 5. Music ducking

Loop the ~30s bed with `-stream_loop -1`, duck it under the narration via sidechain
compression keyed on the VO:

```
[1:a]atrim=0:<D>,volume=<vol>,afade=t=out:st=<D-2.8>:d=2.8[mus];
[0:a]asplit=2[vomix][vokey];
[mus][vokey]sidechaincompress=threshold=0.09:ratio=4:attack=25:release=450:makeup=1[musd];
[vomix][musd]amix=inputs=2:duration=first:normalize=0,
  loudnorm=I=-13:TP=-1.5,afade=t=out:st=<D-2.0>:d=2.0[aout]
```

Sidechain beats a static volume cut: music breathes back up between lines instead of
sitting flat.

## 6. Fades

Audio fade over the last 2s, video fade to black over the last 2s:
```
-vf "fade=t=out:st=<D-2.0>:d=2.0"
```
An abrupt cut to black is the most common "feels unfinished" complaint.

## 7. Logo overlay

```
[1:v]scale=300:-1,format=rgba,colorchannelmixer=aa=0.95[lg];
[0:v][lg]overlay=x=34:y=40:enable='between(t,<start>,<end>)'
```

Place it deliberately. Over a centred presenter it lands on their face; the pillarbox
bar beside them is dead space that suits it well. Check a rendered frame rather than
assuming. Prefer a white-on-transparent variant over dark footage — it will look blank
in an image previewer, which is expected.

## 8. Verifying the result

Cheap checks worth running before delivering:

```bash
# duration / resolution / codec
ffprobe -v error -show_entries format=duration -show_entries stream=width,height,codec_name out.mp4

# frame duplication in a window (higher = smoother; ~50% duplication means judder)
ffmpeg -ss <t> -t 6 -i out.mp4 -vf mpdecimate -vsync vfr -f rawvideo -y /dev/null -stats 2>&1 | tail -1

# geometry against the source
python3 scripts/verify_geometry.py --frame frame.png --source photo.jpg --crop-caption
```

Extract a few frames and actually look at them — caption overflow, logo placement and
crop errors are obvious in a still and invisible in a duration check.
